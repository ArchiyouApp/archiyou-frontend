# Archiyou web

All web frontend applications of Archiyou. This includes the apps:

- Workspace: Total create suite including workspace manager, script editor and community showcase
- Viewer/Configurator: Lightweight embeddable viewers of parametric models and outputs

## Develop

```bash
# clone from repo with submodules
git --recursive clone https://gitlab.com/mvdnet/archiyou-web.git
# install dependencies with pnpm 
pnpm
# start dev server
pnpm dev

```
